# 设置与账号弹窗整理（2026-10-29）

## 背景

上一轮把 9 个设置页合并成 5 个顶级分类，但实现方式是同一滚动区里拼接多个 panel：
「搜索与 AI」一页同时出现网页搜索、AI 供应商摘要、AI 配置表单和调用统计；
「同步与数据」把同步管理和本地数据混排；「安全与隐私」把账号级加密、本机解锁和隐私空间放在一起。
由此出现重复标题（“数据加密”出现两次、“AI 配置”出现两次）、重复操作（立即同步、导出各两处）、
跨页跳转按钮（“管理数据加密”“打开 AI 配置”）以及 1500px 以上的长页面。

## 方案

- 保留 5 个顶级分类，内容多的分类增加二级标签，一次只显示一个 panel：
  - 搜索与 AI：网页搜索 / AI 配置 / 调用概览
  - 同步与数据：同步 / 数据管理
  - 安全与隐私：数据加密 / 本机解锁 / 隐私空间
- 取消运行时注入 panel 标题和分组分隔线；标题由二级标签承担，避免“标题套标题”。
- 内容归位：
  - 昵称移到账号页（个人资料）。
  - 打开方式从搜索页移到外观页的“链接”小节。
  - 侧栏、时钟合并到外观页，用轻量小节标题分组。
  - 数据加密、本机解锁从账号页移出，账号页只保留登录、设备、退出与删号。
  - “管理数据加密”按钮、“打开 AI 配置”按钮移除；AI 配置页直接显示表单与保存按钮。
- 去重：
  - 账号页不再重复“立即同步”和同步状态；同步徽章直接打开同步页。
  - 移除账号页的云端导出；数据管理只保留一个“导出备份”入口，并说明加密时的行为。
  - AI 配置页不再显示供应商摘要；表单本身就是配置。
- 状态处理：
  - AI 配置未登录或未开启主加密时显示说明与跳转按钮，而不是空表单。
  - 只有 AI 配置子页显示“保存 AI 配置”；此时“完成”降为次要按钮，避免两个主按钮。
  - 二级标签支持左右方向键切换，移动端使用原生 select 选择顶级分类。

## 验证

- `node --test web-tests/unit/*.test.mjs`：8/8 通过。
- `web-tests/reliability.mjs`：20/20 通过（新增隐私空间二级标签入口）。
- 桌面 1440×900 与移动端 390×844 逐页截图检查；无 JS 异常。
- 加密账号验证：AI 子页可直接加载供应商表单，保存按钮为主操作；AI 菜单“管理 AI 配置”仍能直达该子页。
- 访客验证：AI 页显示登录引导，账号页显示昵称 + 登录/注册。

## 兼容边界

- 不涉及数据格式、同步协议和加密协议。
- `openHub()` 仍接受 `account`、`appearance`、`search`、`sync`、`privacy`，并新增 `ai`、`usage`、`data`、`encryption`、`device`、`privacy-space` 直达子页。
- `/api/v1/account/export` 保留，仅移除重复的 UI 入口。
- 静态资源与 Service Worker 版本从 `20261029-36` 提升到 `20261029-37`，避免旧 shell 继续使用缓存的 app.js。
