# 功能与界面优化（2026-10-29）

## 范围

- 首页与命令面板复用本地检索，提供分组建议、键盘选择和锁定清理；默认 Enter 保留网页/AI/网址行为，不自动发送输入。
- 设置收敛为五类，保留原分类深链；历史增加关键词/类型筛选，明确缓存与重新搜索。
- JSON 导入先预览，默认合并、可选替换；校验数量/字节预算，先保存带账号归属的单份快照，写入失败不替换当前数据。
- 备忘录新增批量整理；失败撤回本次批量修改，冲突后按实际生效数量反馈，加载期间禁用批量提交。
- 后台配置改为摘要与编辑模态，每次仅提交当前组字段；密码留空保留，取消不保存。
- 保留四季主题，统一控件、字号与焦点，调整窄屏布局；新增样式纳入二进制与 PWA 缓存。
- 自定义搜索引擎标识前后端统一允许 50 字节，兼容已有 c-UUID 标识，无数据迁移。

## 验证

使用独立 8081 服务、独立测试 PostgreSQL（55433）与专属可见 Chrome；未向现有业务数据库写测试数据。

已检查首页建议鼠标/键盘/Esc/锁定清理；历史筛选后删除正确对象；JSON 取消、去重合并、保留设置和存储失败；备忘录筛选全选、批量标签、归档与取消归档、删除确认、存储失败；模拟云端冲突后再次保存失败，确认撤回批量操作、保留远端新增数据且不静默重试。后台取消、保存、503 失败保留输入。查看桌面与 390px 窄屏截图，并检查横向溢出与脚本异常。自定义引擎标识导出再导入及服务端写入通过；跨账号快照恢复被阻止；备份写入失败时导入停止。

所有根目录 JavaScript 执行 node --check；internal/docval 单元测试覆盖自定义引擎标识与上限。构建限制 GOMAXPROCS=12 / -p 12，nice -n 10。

## 兼容边界

旧的无账号归属快照被禁用恢复，避免跨账号恢复；没有删除其内容。保留原同步协议、加密结构及单份当前数据，不引入会话历史或多版本系统。未调用真实 AI 上游、发送测试邮件，也未运行全量数据库集成测试。后台既有多管理员同时更新的并发覆盖问题不在本轮改动范围。
